# Histórico de Atualizações do Projeto (Commits)

Este documento apresenta o relatório do histórico de desenvolvimento do PETBSI-SCRUM, extraído diretamente dos logs de versionamento (Git/GitHub).

> **Sobre o histórico de commits:**
> Diferente de relatórios convencionais em que novas versões substituem as antigas, o Git funciona por **empilhamento estruturado**. Cada novo commit (ponto de salvamento) é salvo *em cima* do anterior. Isso significa que **os commits mais recentes nunca substituem ou apagam os anteriores**; a linha do tempo e todo o histórico do projeto ficam registrados permanentemente, permitindo rastreabilidade e até mesmo reversão caso necessário.
